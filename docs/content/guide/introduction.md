smoothdev is a repository of tools. Each one is small, does one job, and is meant to be used from the command line.

| tool | what it does |
|---|---|
| [smoothdev-web](../tools/smoothdev-web/index.md) | Run a Vite + Fable + .NET web app in dev and prod from one place |

The .NET SDK is pinned in `global.json` at the repository root. Dependencies are paket.

:::tip Editing this site
From the repository root, `dotnet run --project docs -- watch`. The page reloads as you type.
:::
